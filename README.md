# 📰 AI News Summarizer (PHP Native + IBM Granite)

Proyek ini adalah aplikasi web sederhana berbasis PHP Native yang dapat merangkum berita secara otomatis menggunakan **IBM Granite Model (Granite Instruct)** melalui **Replicate API**.

## 🚀 Fitur
- Input berita panjang (teks bebas).
- Pilihan mode ringkasan:
  - 3 Kalimat (singkat).
  - 5 Kalimat (lebih detail).
  - Bullet Points (poin-poin ringkas).
- Hasil ringkasan ditampilkan langsung di browser.

## 🛠️ Teknologi
- PHP 8.2 (XAMPP).
- HTML sederhana untuk frontend.
- IBM Granite 3.3 8B Instruct (via Replicate API).
